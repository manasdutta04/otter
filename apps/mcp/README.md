# Otter MCP bridge 🦦

Run as a stdio JSON-RPC process:

```bash
export OTTER_API_URL=http://localhost:8000
export OTTER_SESSION=your_session_token
python apps/mcp/server.py
```

Tools: `repository_intelligence`, `repository_chat`, `repository_plan`, `repository_review`, `repository_health`, `repository_memory`.

Same product contract as the Otter web app and CLI.
