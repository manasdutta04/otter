# Otter VS Code extension

Commands for repository intelligence, chat, review, health, plans, and memory — against your local Otter API.

## Configure

- `otter.apiUrl` — default `http://127.0.0.1:8000`
- `otter.session` — from `otter login` / web Connect GitHub cookie flow

## Develop

Open this folder as an Extension Development Host project, or follow the root [CONTRIBUTING.md](../../CONTRIBUTING.md).
